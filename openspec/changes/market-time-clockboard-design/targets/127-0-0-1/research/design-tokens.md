# Primary target design tokens

## Palette Evidence

Measured roles come from `palette-evidence.json`, `dom-colors.md`, and `raster-colors.md`.

## Semantic Roles

- page ground → `--mt-bg`
- panel → `--mt-card`
- primary text → `--mt-text`
- time signal → `--mt-needle`

## Palette Relationships

Cool, low-saturation dark fields dominate. Text is the brightest role; the warm needle is sparse
and only denotes the selected instant or an action tied to time.
