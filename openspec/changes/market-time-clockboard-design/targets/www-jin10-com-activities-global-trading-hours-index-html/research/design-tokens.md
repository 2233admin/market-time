# Reference target design tokens

## Palette Evidence

Measured evidence is in `palette-evidence.json`, `dom-colors.md`, and `raster-colors.md`.

## Semantic Roles

- page ground → `--mt-bg`
- card → `--mt-card`
- primary text → `--mt-text`
- time needle → `--mt-needle`

## Palette Relationships

The reference uses near-black ground, slightly lighter schedule cards, high-contrast text, and a
sparse warm cursor. Mark Time preserves these relationships while using its own phase semantics.
